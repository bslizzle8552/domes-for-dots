# Changelog

## 0.2.0 — 2026-10-02

- Added a JSON proposal/plan/apply/recovery workflow, immutable existing owner locks, optional resource/operation policy, stale-base rejection and durable expansion history.
- Added explicit resident activity state, target versus physical location, previous activity, timestamps and movement phase; retained separate save and simulation semantics.
- Added tagged MOCK activities, authored station preferences, a saved pause control and an arrival light with interruption cleanup.
- Added Nova's original articulated body, six actual AnimationPlayer clips and a loaded-scene character audit.
- Added Lumen's Lantern Archive creation pilot and a telescope expansion using the same runtime.
- Kept the v0.1 engine, state schema, working examples and native-call truthfulness boundary. See [V2 build record](docs/V2_BUILD.md) for verification and limits.

## 0.1.0 — 2026-10-02

First implementation release; see [BUILD_STATUS.md](BUILD_STATUS.md) for validation and publishing state.

- Added a Godot 4.5.1 3D runtime with data-driven world selection, asset composition, character control and generic stations.
- Added Cedar Atelier and Tidal Observatory, with distinct layouts, content and simulated routines on one engine.
- Defined versioned world, character, asset, routine, brief, runtime-state and activity contracts.
- Added deterministic elapsed-time simulation, finite projects, local saves and bounded mock work/call events.
- Demonstrated a manifest-based wind-chime station extension.
- Added owner/Dot onboarding and expansion prompts that preserve decision ownership.
- Preserved the supplied 2D prototype and research as historical inputs.

Native call/work integration, hosted storage, rig generation, multiplayer and multilevel movement are not included.

# Nova's Tidal Observatory

An orbital research deck connects across a narrow skybridge to an observation
wing. Blue structural forms, a comms orb, holographic console, telescope and a
distant planet give it a different silhouette and purpose from Cedar Atelier.

- [World](../../godot/content/worlds/tidal_observatory.json)
- [Owner and Dot brief](../../godot/content/briefs/tidal_observatory.json)
- [Character](../../godot/content/characters/nova.json)
- [Routine and finite projects](../../godot/content/routines/tidal_observatory.json)
- [Orbital assets](../../godot/content/assets/tidal_observatory.json)

Nova alternates horizon observation, atlas assembly, spectrum archive study,
console notes and rest. The tidal atlas and spectrum project are explicitly
imagined, finite simulations; they are not scientific measurements or new model
work. The comms orb is a visual prop, with mock events available for testing.

This example uses the same engine as [Cedar Atelier](../cedar_atelier/README.md).
The fictional Dot is a replaceable placeholder; no external assistant is connected.

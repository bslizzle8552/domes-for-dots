# Moss's Cedar Atelier

A connected cedar studio and outdoor herb terrace, with amber furniture, sage
plants, a reading corner and a separate wind-chime station. Moss's routine
alternates field journals, craft, gardening, music, desk notes and rest.

- [World](../../godot/content/worlds/cedar_atelier.json)
- [Owner and Dot brief](../../godot/content/briefs/cedar_atelier.json)
- [Character](../../godot/content/characters/moss.json)
- [Routine and finite projects](../../godot/content/routines/cedar_atelier.json)
- [Studio assets](../../godot/content/assets/cedar_atelier.json)
- [Independent wind-chime extension](../../godot/content/assets/wind_chime.json)

The mobile and herb bed change visually as their finite simulated projects
advance. The wind chime demonstrates adding a manifest, object, station and
routine tag without engine changes. Its visual interaction has no audio.
See the [extension recipe](../README.md#the-data-only-extension).

This example uses the same engine as [Tidal Observatory](../tidal_observatory/README.md).
The fictional Dot is a replaceable placeholder; no external assistant is connected.
